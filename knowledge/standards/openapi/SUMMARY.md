# OpenAPI Specification summary

Full provenance: `SOURCE.md` (Apache-2.0, SHA `447c479c`).

## Released versions present (`versions/`)

1.2, 2.0 (Swagger), 3.0.0-3.0.4, 3.1.0-3.1.2, **3.2.1** (latest). Each also has a `-editors.md` companion (working-draft formatting). `_archive_/` holds a few pre-1.0 historical drafts plus the legacy 1.2/2.0 JSON Schemas.

## Where the JSON Schemas live

- **1.2 / 2.0 (Swagger)**: static JSON Schema files in-repo at `_archive_/schemas/v1.2/*.json` and `_archive_/schemas/v2.0/schema.json`.
- **3.0.x / 3.1.x / 3.2.x**: generated by `scripts/` and published externally at `https://spec.openapis.org/oas/<version>/schema/<date>` (see `.github/workflows/schema-publish.yaml`) - not checked into this repo. The Markdown under `versions/<x.y.z>.md` is the normative spec text for these.

## How the kit should use it

- **API contracts**: NestJS services expose their contract via `@nestjs/swagger` decorators; the resulting document is the project's OpenAPI artifact, not a copy of this repo.
- **Version target**: match whatever OpenAPI version the installed `@nestjs/swagger` emits by default (3.0) unless a project needs a 3.1+-only feature (`webhooks`, JSON-Schema-2020-12-aligned `type` arrays) - then read `versions/3.1.1.md` or `versions/3.2.1.md` here.
- **Client generation**: run codegen (`openapi-typescript`, `orval`, etc.) against the live generated document from the running NestJS app (`/api-json`), never against this repo.
