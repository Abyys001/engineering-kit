## Rules this file obeys

- A source repository existing under `sources/` is never an implementation. It makes a feature `reference`, never `available`.
- A feature being `core` for a domain is domain knowledge, not project scope (see [`../product-builder/PRODUCT-BUILDER.md`](../product-builder/PRODUCT-BUILDER.md) §2).
- A domain stays `partial` until the gate passes. Promoting one to make the catalog look complete is the failure this file exists to prevent.
- Compliance items are never features and never claim a product is compliant.
