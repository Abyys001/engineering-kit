# Project management features

Generated by hand from `feature-map.json` (26 features). Tenant-defined custom fields are covered by
the shared `shared.custom_fields` platform capability, not a domain-specific feature here.

## Core

| Feature | Description |
|---|---|
| `project-management.workspaces` | Top-level container for projects, members, settings. |
| `project-management.projects` | Container for a related set of tasks. |
| `project-management.tasks_issues` | The core unit of work. |
| `project-management.subtasks` | Breaking a task into tracked child tasks. |
| `project-management.statuses_workflows` | Configurable, grouped per-project statuses. |
| `project-management.boards_kanban` | Columns + swimlanes, drag-and-drop cards. |
| `project-management.task_dependencies` | Typed, bidirectional task relations. |
| `project-management.comments_mentions` | Threaded discussion with @-mentions and reactions. |
