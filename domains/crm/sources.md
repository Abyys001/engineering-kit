## Notes

- **`nextcrm`** (b46b563b61c948a07a9cc5a340032444db1f8188): Verified full LICENSE file: plain MIT, no exceptions. Rich Prisma schema (~90 models). Confirmed models: crm_Contacts, crm_Accounts (with member_of parent-account field), crm_Leads (lead_source/status/type lookups, assigned_accounts FK, no explicit convert action found), crm_Opportunities + crm_Opportunities_Sales_Stages + crm_OpportunityLineItems + approval_status workflow (quote/SOW approval before sending), crm_FunnelSettings (kill/recycle/cadence-touch follow-up timers), crm_Activities + Tasks (polymorphic activity links), crm_Products/crm_ProductCategories/crm_AccountProducts, crm_Targets/crm_TargetLists (segmentation, tags, do-not-email), crm_campaigns, crm_Report_Config/crm_Report_Schedule, EmailAccount/Email (IMAP/SMTP sync), CalendarConnection/crm_CalendarEvents (Google OAuth). Confirmed CSV import for products (actions/crm/products/import-products.ts) and targets (actions/crm/targets/import-targets.ts), not contacts specifically. Copy-safe.
- **`espocrm`** (LICENSE.txt read in full (root)): License corrected from an initial GPL-3.0 assumption to the actual AGPL-3.0 after reading LICENSE.txt directly; reference-only, never copy code. Directly read application/Espo/Modules/Crm/Resources/metadata/entityDefs/: confirmed core entities Account, Contact, Lead, Opportunity, Campaign, TargetList, Task, Call, Meeting, Document, Case. Read Opportunity.json (stage/probability/amount/closeDate) and Lead.json (status/source/opportunityAmount/targetLists/convertedAt/createdOpportunity — explicit lead-conversion fields) directly. No native Quote or forecasting entity found in core.
