## Notes

- **`chatwoot`** (b8eb7766f2735d6e3bf5ed3a69cf453b289a4411): License verified directly from root LICENSE ('Content outside of the above mentioned directories ... available under MIT Expat') plus a separate enterprise/LICENSE file; copy-safe for core code only, never the enterprise/ tree. app/models/message.rb confirms a boolean `private` field (internal notes). app/models/label.rb confirms tags/labels. conversations.status enum: open/resolved/pending/snoozed; sla_policy_id FK + AppliedSla model confirm core (non-enterprise-gated) SLA support. Macro model with actions including change_status/assign_team/send_webhook_event. Article model + portal/category/folder confirm a knowledge base. CsatSurveyResponse model (rating+feedback) confirms CSAT. api/v2/accounts/{reports,live_reports,summary_reports}_controller.rb (core, not enterprise/) confirm reporting/analytics.
- **`zammad`** (677594465724afc892449b1beb398b050837cc83): License verified directly from root LICENSE (full AGPL-3.0 text); reference-only, never copy code. Ticket::State model (seeded): new, open, pending reminder, pending close, closed, merged. Explicit Sla model (response_time/update_time, condition-matched) plus an escalation calculation engine. calendar.rb confirms business-hours/holiday calendars. trigger.rb (condition/perform store) confirms rule-based automation. tag.rb confirms tagging. Customer role belongs_to on Ticket confirms a customer-facing portal role.
- **`osticket`** (8d38b0619649a50ee7cbbf37085f5d297fdc6f36): License verified directly from root LICENSE.txt (GPL-2.0 text) and GitHub's license API; resolves a conflicting earlier assumption of Apache-2.0 in favor of the actual GPL-2.0. Reference-only, never copy code. Ticket states via hasState() checks: open, resolved, closed, archived, deleted. SLA model with grace_period and FLAG_ESCALATE/FLAG_NOALERTS bitflags. class.knowledgebase.php/class.faq.php confirm a knowledge base. class.canned.php confirms canned responses. A dedicated client/ directory confirms a customer portal. class.thread.php has an explicit 'N' => 'note' entry type plus a FLAG_SYSTEM system-note flag, confirming internal notes.
- **`freescout`** (77175143d91dfa354cd8d1655ef611e0e1c471bc): License verified directly from root LICENSE (full AGPL-3.0 text); reference-only, never copy code. Conversation status enum: active(1)/pending(2)/closed(3)/spam(4) (STATUS_OPEN=5 is dead code, superseded by active). TYPE_EMAIL/PHONE/CHAT/CUSTOM channel enum confirms multi-channel support including phone. No SLA model found in core — confirms SLA is a paid Modules/ add-on here, not core AGPL code; this caps freescout's contribution to the SLA/escalation feature at zero (excluded from that feature's source list).
- **`ftc-tsr`** (16 CFR 310, current as retrieved): Verified live via WebFetch: exact page title confirmed on ftc.gov.
- **`gdpr-2016-679`** (OJ L 119, 4.5.2016; CELEX 32016R0679): Verified live via WebFetch: title and CELEX number confirmed. Same source entry independently kept per domain per schema.
