# Logistics features

Generated by hand from `feature-map.json` (30 features). Run `tools/kb.py build` to regenerate the
catalog-wide views; this file is the human-readable grouping for this domain.

## Core

| Feature | Description |
|---|---|
| `logistics.customers_shippers` | Accounts for businesses/individuals who book shipments and orders. |
| `logistics.shipments` | A booked movement with a carrier: parcels, label, status, tracking number. |
| `logistics.rates_quotes` | Requesting and comparing carrier rates before booking. |
| `logistics.carriers` | Connected carrier accounts and their service levels. |
| `logistics.labels` | Generating and storing the carrier shipping label/invoice. |
| `logistics.tracking_events` | Append-only timeline of scan/status events. |
| `logistics.proof_of_delivery` | Photo/signature capture at the delivery stop. |
| `logistics.dispatch` | Assigning a driver and vehicle to an order. |
| `logistics.routes` | Sequencing stops into an optimized route. |
| `logistics.drivers` | Driver profiles, licensing, location, availability. |
| `logistics.vehicles` | Fleet vehicle specs and live telemetry. |

## Common

| Feature | Description |
|---|---|
| `logistics.orders` | A customer's request to move goods, ahead of shipment/dispatch. |
| `logistics.parcels` | Physical packages and their commodity line items. |
| `logistics.manifests` | Carrier close-out batches or driver route manifests. |
| `logistics.pickups` | Scheduling a carrier/driver pickup. |
| `logistics.warehouses` | Facilities where inventory is stored or consolidated. |
| `logistics.exceptions_returns` | Flagging delivery problems and processing returns. |
