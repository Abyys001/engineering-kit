## Notes

- **`documenso`**: Reference only, never copy: AGPL plus proprietary ee directory. Not cloned. Read for field-placement, recipient and audit model: packages/{signing,lib,trpc,ui,api}, packages/prisma.
- **`docuseal`**: Reference only: the additional terms block reuse. Not cloned. Informs form/field-schema builder and template model.
- **`opensign`**: Reference only. Parse/MongoDB backend is a poor fit for Postgres; useful for recipient roles, bulk send and template flows. Not cloned.
- **`libresign`**: Reference only. Nextcloud/PHP; useful for PKCS#12 certificate-based PDF signing and verification-page concepts. Not cloned.
- **`papermark`**: Reference only. Not an e-signature tool; informs link sharing, data rooms and view analytics. Not cloned.
- **`svix-webhooks`**: Signing/retry design informs webhook delivery. Self-hosting the server is not justified; implement the Standard Webhooks format in NestJS.
- **`standard-webhooks`**: Verified: headers webhook-id, webhook-timestamp (unix seconds), webhook-signature (space-delimited); signed content is id.timestamp.payload; HMAC-SHA256 secrets whsec_+base64; dual-signing for rotation; the spec sets no timestamp tolerance.
- **`owasp-forgot-password`**: Verified: CSPRNG tokens, sufficient length, secure storage, single use, expiry, rate limits; warns account lockout enables DoS, so lock the token or OTP challenge instead.
- **`drizzle-rls`**: Verified: pgPolicy, pgRole, .withRLS(); default deny with no policy; the app must set the session variable/role inside a transaction.
- **`pdfjs`**: Browser renderer; also runs on Node with a worker. viewport.convertToPdfPoint handles CropBox and rotation. Set isEvalSupported:false.
- **`react-pdf`**: Thin React wrapper over pdfjs; viewer plus overlay layer for field editing.
- **`cantoo-pdf-lib`**: Maintained fork of pdf-lib (upstream 1.17.1 last published 2022-05-12). Stamping, merging, AcroForm flattening; loads whole file in memory.
- **`signpdf`**: Placeholder plus detached CMS signing; PAdES-B-B level only. No DSS/VRI (B-LT/LTA is custom work).
- **`pkijs`**: CMS, TSP (RFC 3161) and OCSP/CRL on WebCrypto. Replaces node-forge (BSD-3-Clause OR GPL-2.0, ASN.1 CVE history).
- **`pdfkit`**: Server-side generation of the completion certificate.
- **`signature-pad`**: Canvas signature capture; use directly rather than react-signature-canvas.
- **`pdfme`**: Only permissive drag-and-drop template/field designer; embeddability in Next.js and per-package licence unchecked.
- **`embedpdf`**: Headless plugin viewer on PDFium/WASM. Reference; duplicates react-pdf.
- **`docusign-esign-node`**: Envelope, recipient and tab vocabulary; use only for a DocuSign integration or migration import.
- **`mupdf-js`**: Rejected: needs a commercial licence for closed-source SaaS.
- **`iso-32000`**: User space is bottom-left origin in points; visible area is CropBox (defaults to MediaBox); /Rotate applies on top. Basis for storing fields as page-relative fractions. Summary page only; prior knowledge for details.
- **`rfc-3161`**: Trusted timestamp tokens for signed-document evidence. Cited from prior knowledge; not fetched this session.
- **`etsi-pades`**: Baseline PAdES levels B-B, B-T, B-LT, B-LTA. Cited from prior knowledge; not fetched this session.
- **`eidas-910-2014`**: Distinguishes simple, advanced and qualified electronic signatures and qualified trust services. Not fetched this session; engineering implications only, counsel must confirm.
- **`esign-act`**: Consent to electronic records, intent to sign, record retention and reproducibility. Not fetched this session.
- **`ueta`**: State-level counterpart to ESIGN; attribution, record retention. Not fetched this session.
- **`uk-eidas-2016`**: UK trust-service regime and evidentiary treatment of electronic signatures. Not fetched this session; confidence low, counsel must confirm current text.
- **`uae-46-2021`**: Recognises electronic signatures, seals and trust services in the UAE. Not fetched this session; confidence low, counsel must confirm.
- **`gdpr-2016-679`**: Lawful basis, retention limits, erasure vs audit retention, data residency. Same source as other domains; engineering implications only.
- **`owasp-asvs`**: Verification checklist for auth, session, access control (IDOR/BOLA), file upload and API security. Cited from prior knowledge; not fetched this session.
